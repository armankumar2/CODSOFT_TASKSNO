# Rule-Based Chatbot (Vanilla Web)

A purely local, educational web application that demonstrates basic natural language intent detection using JavaScript regular expressions and predefined rules.

## Features
- **Zero Dependencies**: Built entirely with HTML, CSS, and Vanilla JavaScript. No build tools or external servers needed.
- **Local Rule Engine**: Matches user input against predefined regex patterns (e.g., Greetings, Help, Identity) and returns a matching response instantly.
- **Modern UI**: A responsive, clean design featuring a dark/light mode toggle and persistent chat history saved locally in your browser's `localStorage`.
- **Educational Visualizations**: Includes an interactive "Supported Intents" grid and a visual "How It Works" pipeline explaining the logic.

## How to Run
1. Open the folder containing this project.
2. Double-click the `index.html` file to open it in any modern web browser (Chrome, Firefox, Safari, Edge).
3. Start chatting!
