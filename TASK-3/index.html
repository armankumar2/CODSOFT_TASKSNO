Model Information

Learn about the architecture and dataset behind our Image Captioning AI.

Computer Vision

ResNet50

Pretrained convolutional neural network used for extracting visual features. ResNet50 analyzes the image and creates a dense vector representation of the visual information, identifying objects, textures, and spatial relationships.

Language Generation

LSTM (Long Short-Term Memory)

Sequence model used to generate the caption word by word. The LSTM network takes the visual feature vector from the CNN and translates it into a natural language sequence, maintaining context throughout the sentence generation.

Dataset

Flickr8k

Image-caption dataset used for training and evaluation. It contains 8,000 images, each paired with five different human-annotated captions, providing a robust baseline for everyday scenes and activities.
